                          Look at these first
                          
                
                            
                
                            
                
                            
                  
                              
                  
                              
                
                              
              
                              
              
                              
                
                              
                  
                              Commit
                              
                  
                              Press Status to see the branch.
                              
                  
                              
                    
                    
                  
                              
                  
                              Commits every change in the sandbox's clone. To commit on a branch of your own, make one first below: switch -c my-branch.
                              
                
                              
                
                              
                  
                              Pull and push
                              
                  
                              Sent from this computer with your key; your SSH agent may ask you to approve. Pushing to main or master, deleting branches and tags are refused before anything is sent.
                              
                  
                              
                    
                    
                    
                  
                              
                  
                              
                    
                              Your uncommitted changes are in the way. Pull can set them aside, pull, then put them back: pull --autostash.
                              
                    
                              
                      
                    
                              
                  
                              
                  
                              
                  
                                
                  
                                
                
                                
                
                                
                  
                                Git command
                                
                  
                                
                    
                    
                  
                                
                  
                                Any Git command, such as stash, switch -c fix or rebase main. It runs inside the sandbox, never on this computer, so hooks and settings in the clone run there too. Only fetch, pull and push reach the remote, with your key, through the same checks as the buttons. Quote an argument with spaces: commit -m "Fix the refund total".
                                
                
                                
                
                                Commit, pull and push are for a project cloned from Git. A folder you added stays yours: commit in it as usual, then Destroy and Start to bring the new commit in.
                                
              
                                
            
                                
          
                                

          
                                
            
                                
              
                                
                
                                Your secrets
                                
                
                                
              
                                
              
                                Each value is stored in your keychain by the daemon. You can set or replace one here, but nothing in this window can show a value, even to you.

Nothing here shows a value, and changing the file later changes nothing until you use it again.
                                      
                
                                      
                
                                      
                  
                  
                
                                      
              
                                      
              
                                        
              
                                        
                
                
                
                                        
                  Give it to
                  
                                          
                  
                                          
                
                                          
                
                                          
                  
                  
                
                                          
              
                                          
              
                                          A service can read every secret it is given. New values reach a running sandbox on its next start. The daemon's audit log records the name, never the value.
                                          
            
                                          
            
                                          
              
                                          Where they could go
                                          
              
                                            
              
                                            A service can read what it is given. A secret held by the proxy also needs the gateway to terminate TLS, which is not settled, so a plan with one is refused.
