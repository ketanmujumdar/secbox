              Secrets
              
          
              Secrets are stored, and assigned ones are delivered on each start.
              
          
              Use the secrets command to add and assign them. A service can read what it is given. A secret held by the proxy also needs the gateway to terminate TLS, which is not settled, so a plan with one is refused.
              
          
              Managing secrets from this window is not built yet. Values are never shown here.
